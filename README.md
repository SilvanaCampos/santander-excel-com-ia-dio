
# Santander - Excel com Inteligência Artificial (DIO)

Este repositório reúne os projetos desenvolvidos durante o curso
Santander - Excel com Inteligência Artificial, oferecido pela
Digital Innovation One (DIO).

## Projetos Desenvolvidos

### 📈 Desafio 01 - Simulador de Investimentos em Fundos Imobiliários

Ferramenta em Excel para projeção de investimentos em FIIs.

Principais recursos:

- Simulação de aportes
- Cálculo de patrimônio acumulado
- Estimativa de dividendos
- Comparação de cenários

---

### 🧾 Desafio 02 - Organizador de Declaração de Imposto de Renda

Ferramenta para organização das informações da declaração de IR.

Principais recursos:

- Cadastro de dependentes
- Controle de rendimentos
- Controle patrimonial
- Validação de informações

---

### 🎮 Desafio Final - Dashboard de Vendas Xbox

Dashboard interativo desenvolvido em Excel.

Principais recursos:

- Tabelas Dinâmicas
- Segmentação de Dados
- Indicadores de desempenho
- Visualização de vendas

---
## 🛠️ Tecnologias Utilizadas

- Microsoft Excel
- Fórmulas Avançadas
- Tabelas Dinâmicas
- Dashboards
- Análise de Dados
